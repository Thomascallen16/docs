# Accountability Ecosystem Documentation

This repository is the documentation source for the Accountability Ecosystem.

The ecosystem is built around one principle:

> **Don't ask people to trust the system. Give them the sources and the means to verify.**

## Architecture

See [ECOSYSTEM_ARCHITECTURE.md](ECOSYSTEM_ARCHITECTURE.md) for the canonical product, repository, deployment, identity, billing, and accountability model.

## Documentation goals

Documentation should explain how the ecosystem works without presenting software output as individualized legal advice. Source links, evidence provenance, uncertainty, conflicts, limitations, and verification procedures should remain explicit.

## Publishing

This repository uses Mintlify documentation infrastructure. Production publishing remains dependent on the configured Mintlify/GitHub integration.

## Development

Use the Mintlify CLI with the repository's `docs.json` configuration for local preview when available.
