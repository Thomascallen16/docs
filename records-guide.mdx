# Working With Public Records

A useful investigation starts with a clear record trail.

## Start with identifiers

Before requesting records, collect what you know:

- Agency or office
- Case, incident, report, or docket number
- Names and titles
- Approximate dates and times
- Locations
- Type of record sought

## Ask narrowly enough to search

Specific requests are easier to process and easier to challenge if records are withheld. Ask for identifiable categories, date ranges, and known record numbers when possible.

## Preserve the original

Keep the original response, attachments, headers, metadata, and the request you sent. Do not rely only on screenshots when the original file is available.

## Build a timeline

Record when an event occurred, when a document was created, when it was filed or published, and when you obtained it. Those can be different dates.

## Cite the record

A claim should point readers toward the document that supports it whenever publication rules and privacy concerns permit.
